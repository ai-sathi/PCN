# Viva Questions — A9 Hamming Code Error Correction

**Q1. What is Hamming code?**

A code that adds parity bits to locate and correct a single-bit error in its basic form.

**Q2. Where are parity bits placed?**

At positions that are powers of two: 1, 2, 4, 8, and so on.

**Q3. What is a syndrome?**

A bit pattern or number derived from parity checks that identifies an error position.

**Q4. Can basic Hamming code safely correct multiple-bit errors?**

No. Basic Hamming code is designed for single-bit correction; multiple-bit errors may be miscorrected.

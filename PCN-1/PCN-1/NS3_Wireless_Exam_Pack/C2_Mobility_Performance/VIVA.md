# Viva — C2

1. **What is node mobility?** Nodes change position during the simulation.
2. **What is a mobility model?** A rule that describes how nodes move over time.
3. **Constant-position vs random walk?** One keeps a fixed position; the other changes position according to a random movement process.
4. **Why compare with a static baseline?** To isolate the effect of movement.
5. **What performance changes can mobility cause?** It may affect throughput, delay, PDR and loss.

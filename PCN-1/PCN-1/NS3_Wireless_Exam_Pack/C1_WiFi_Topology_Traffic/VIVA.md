# Viva — C1

1. **What does an AP do?** Provides the infrastructure point that Wi-Fi stations associate with.
2. **What is SSID?** The name identifying a Wi-Fi network.
3. **What do PHY and MAC represent?** Physical layer and medium access control.
4. **Why assign IP addresses?** So IP-layer communication can identify network interfaces.
5. **What does FlowMonitor measure?** IP-flow packet counts, loss, delay and throughput-related statistics.
6. **What is PDR?** Received packets divided by transmitted packets, multiplied by 100.
7. **Why might wireless packets be lost?** Interference, collisions, weak signal, congestion or movement can contribute.

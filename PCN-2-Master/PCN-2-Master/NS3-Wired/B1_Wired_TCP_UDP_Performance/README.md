# B1 run instructions

Copy `Program/wired_simulation.cc` to your NS-3 root's `scratch/` folder, then from the NS-3 root run:

```bash
./ns3 run scratch/wired_simulation
```

Record actual values from your terminal. The PCAP and XML output are created in the working directory. See `QUESTION.md` for the full exam wording and topology parameters.

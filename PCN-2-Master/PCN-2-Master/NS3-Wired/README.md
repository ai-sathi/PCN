# B — NS-3 Wired: 2 Master Questions

- B1: Build the routed wired topology, generate TCP/UDP traffic, collect traces and calculate performance metrics.
- B2: Vary network conditions, demonstrate routing/link failure and compare supported TCP congestion-control algorithms.

Each master question has a dedicated `QUESTION.md`. The implementation variants are nested underneath each master question. Requires a compatible NS-3 installation; these are C++ NS-3 programs, not standalone Python programs.

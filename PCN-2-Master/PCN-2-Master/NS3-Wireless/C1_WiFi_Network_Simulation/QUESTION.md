# C1 — Wireless Wi-Fi network simulation

## Exam question
Create wireless nodes, configure Wi-Fi communication, assign IP addresses and generate traffic. Measure throughput, delay, PDR and packet loss.

## What the program does
- Creates a configurable number of ad-hoc Wi-Fi nodes.
- Uses constant-position mobility.
- Installs Internet stack and assigns IP addresses.
- Sends UDP traffic from the first node to the last node.
- Enables PCAP and FlowMonitor.
- Prints Tx/Rx counts, estimated packet loss, PDR, throughput and average delay.

## Metrics
Throughput (Mbps), average end-to-end delay (ms), packet delivery ratio (PDR), and estimated packet loss.

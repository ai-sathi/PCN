# Viva Questions — A7 Checksum Error Detection

**Q1. What is a checksum?**

A computed value sent with data to help detect corruption.

**Q2. What does the receiver do?**

Recalculates the checksum and compares it with the transmitted checksum.

**Q3. Does a checksum correct errors?**

No, it detects some errors; it does not identify and repair the corrupted data.

**Q4. Can all errors be detected?**

No. Some error patterns can produce the same checksum.

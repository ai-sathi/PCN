# Viva Questions — A8 CRC Error Detection

**Q1. What is CRC?**

Cyclic Redundancy Check, an error-detection method based on modulo-2 polynomial division.

**Q2. What is the generator polynomial?**

The bit pattern representing the divisor used in CRC calculation.

**Q3. What is modulo-2 division?**

Binary division where subtraction is performed using XOR without carries or borrows.

**Q4. Does CRC correct errors?**

Usually CRC is used to detect errors; it does not by itself correct the corrupted bits.

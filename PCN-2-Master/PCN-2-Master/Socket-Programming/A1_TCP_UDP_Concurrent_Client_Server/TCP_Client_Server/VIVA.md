# Viva Questions — A1 TCP Client Server

**Q1. What is a socket?**

An endpoint that lets programs communicate.

**Q2. What is TCP?**

A connection-oriented transport protocol that provides reliable, ordered byte-stream delivery.

**Q3. What does bind() do?**

Associates a socket with a local IP address and port.

**Q4. What does listen() do?**

Marks a TCP socket as ready to accept incoming connections.

**Q5. What does accept() do?**

Accepts a connection and returns a new connected socket.

**Q6. What is a port?**

A number used to identify an application endpoint on a host.

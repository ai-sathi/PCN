# Viva Questions — A6 DNS Simulation

**Q1. What is DNS?**

A distributed naming system that maps domain names to resource records, including IP addresses.

**Q2. What is name resolution?**

Finding a record associated with a domain name.

**Q3. Why return an error for an unknown domain?**

To indicate that the requested name is not present in the toy database.

**Q4. Is this a complete DNS implementation?**

No. It is a simplified database lookup over UDP, not the full DNS wire protocol.

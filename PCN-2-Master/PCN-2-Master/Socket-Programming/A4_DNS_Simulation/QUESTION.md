# A4 — DNS simulation

## Exam question
Implement a domain-to-IP database, name resolution and error handling for unknown domains.

## What to demonstrate
- Store domain-to-IP mappings in the server's dictionary/database.
- Send a domain name from the client to the server.
- Return the IP address for a known domain.
- Return a clear not-found response for an unknown domain.

## Metrics
Lookup response time and success rate. This is a simplified DNS simulation over UDP, not a complete standards-compliant DNS server.

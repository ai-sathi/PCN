# A2 — HTTP webpage download using TCP sockets

## Exam question
Develop a socket-based HTTP client that connects to a local HTTP server, sends a GET request and downloads the webpage.

## What to demonstrate
1. Create a small `index.html` file in a local folder.
2. Start Python's local HTTP server.
3. Run the socket client to send an HTTP GET request.
4. Save the returned webpage to a file and verify its contents.

## Metrics
The program reports download duration, received byte count and approximate throughput. The exact timing depends on your machine and local server.
